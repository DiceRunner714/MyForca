# MyForca

> Jogo da forca para terminal, com palavras em português, feito em Python.

---

## Como Jogar

**Pré-requisito:** Python 3 instalado.

```bash
python forca.py
```

A cada rodada, uma palavra secreta é sorteada e você deve adivinhar letra por letra. São permitidos **6 erros** antes do 'enforcamento'.

Você também pode tentar adivinhar a palavra inteira de uma vez digitando ela completa.

## Palavras

O arquivo `palavras.txt` contém mais de 150 palavras distribuídas em quatro categorias:

- 🍎 **Frutas**
- 🎨 **Cores**
- 🪑 **Objetos**
- 🐾 **Animais**

Para adicionar palavras, basta editar o `palavras.txt` com uma palavra por linha.
